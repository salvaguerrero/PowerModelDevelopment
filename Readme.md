# Development: Cost Minimization Model for Power Markets Simulations  

A small Julia-based framework for simulating and minimizing total generation cost of a power market. This project formulates a linear optimization problem that dispatches generation units to meet demand at minimum cost, subject to capacity, ramping, and others constraints.

## Stack
- Julia Lang with JuMP + Gurobi (or other solvers)
